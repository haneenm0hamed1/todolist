# Todo List App

This is a simple **Todo List** web application built to practice JavaScript, HTML, and CSS fundamentals.

## Features
- Add, edit, and delete tasks
- Mark tasks as completed
- Filter tasks by status (All, Completed, Pending)
- Responsive design for desktop and mobile

## Tech Stack
- HTML
- CSS
- JavaScript
